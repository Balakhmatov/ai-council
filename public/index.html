Подключения

Ключи хранятся только в памяти этой вкладки. Подписки на чаты не заменяют API-баланс.

Запросы из браузера отправляются в OpenRouter. Идентификаторы моделей можно изменить ниже.

Ключи провайдеров задаются в окружении сервера. Не отправляйте ключи неизвестным посредникам. Для GitHub Pages нужен отдельный HTTPS-сервер.
