# Изображения кроссоверов

Портреты исторического совета, сатирического эфира, аниме, Mortal Kombat, комедий об ангелах и демонах и об Олимпе созданы для этого вымышленного шоу. Это художественные иллюстрации, не фотографии или официальные материалы франшиз. Афиша совета злодеев также создана для шоу.

Текущие афиша и семь портретов Marvel/DC предоставлены пользователем в архиве `213.zip` и преобразованы в WebP без изменения размеров 784×1168. Исходники сопоставлены так: `HawOY` — афиша, `C0mBi` — Джокер, `SUtTR` — Танос, `tMnfk` — Доктор Дум, `Cq7Dr` — Локи, `VTEre` — Харли Квинн, `GW7pe` — Лекс Лютор, `6YlK9` — Магнето.

Старые афиши восстановлены. Новые афиши — отдельные цельные сгенерированные сцены, а не композиции из портретных карточек. Исходные изображения не загружаются с внешних сайтов при просмотре приложения.

`show-comic-luthor-generated.webp` — новый сгенерированный портрет Лютора. Прежний `show-comic-luthor.webp` больше не используется в карточке. Ранее генерация сцены Marvel/DC и шести портретов отклонялась сервисом с кодом `moderation_blocked`. Текущие изображения взяты из пользовательского архива `213.zip`, а не из тех неудачных запросов.

`show-{time,reality,anime,kombat,olympus,afterlife}-poster-vertical.webp` — вертикальные версии сцен, заново скомпонованные генератором из предыдущих иллюстраций, 1024×1536. Они заменяют горизонтальные `*-scene.webp` в интерфейсе, который показывает сцену целиком.
