# Свободные криминальные истории

Эксперимент включён только для `diner` и `heist`. Остальные восемь сюжетов используют прежние сценарные повороты и финалы; варианты ремарок при сбое API расширены для всех десяти историй.

- В «Последнем столике» один из трёх внешних импульсов выбирается при запуске и появляется во втором круге: посланник Хозяина, вмешательство патруля или отключение света. Импульс не назначает виновного, победителя или финал.
- «Ограбление без плана» развивается без заданных внешних поворотов. Актёрам известны только собственные характер и личные сведения, общая ситуация, состоявшиеся реплики и подтверждённые события. Общие `truth`, `beats`, `ending` из старой библии им не передаются.
- Очередь учитывает обращения и реакцию пострадавшего; участник может ответить повторно внутри одного круга. Число запросов не превышает прежний бюджет `min(актёры, 4) × сцены + 1`.
- В каждом круге доступна одна более длинная реплика до 160 слов. Остальные получают пределы 45 или 90 слов; лимит не требует заполнять весь объём. Двойное обрезание ответа до 320–360 символов отключено для экспериментального пути.

## Действия и последствия

Актёр возвращает скрытый от зрителя JSON: `speech` и необязательный `action` (`hit`, `bind`, `kill`, `release`, `escape`). Зритель получает речь и отдельную сценическую ремарку. Обычный текст без JSON также принимается как реплика, но не меняет физическое состояние.

Приложение проверяет цель и состояние участников. Удар оставляет ранение; связывание может не удаться; смертельная атака может закончиться ранением вместо смерти. Исход спорного действия выбирается приложением, а не утверждением самого атакующего. Связанный способен говорить, но не нападать. Погибшие и покинувшие комнату исключаются из очереди. Состояние закреплено в каждом последующем запросе, даже когда старые реплики уже не помещаются в окно контекста. Насилие описывается без натуралистических подробностей.

## Эпилог

Остаётся один отдельный запрос. До 220 слов: последний кадр и драматические последствия реально состоявшихся действий. Модель получает подтверждённые события и итоговое состояние персонажей; ей запрещено выдумывать новое убийство, спасение или примирение ради финала. Если генерация не удалась, выводятся зафиксированные последствия, а не старая каноническая развязка.

## Проверки

Тестируются три ветви импульса, отсутствие авторского финала и утечки чужих секретов в обоих сюжетах, разные длины реплик, сохранность ранений/пут/смерти, удаление погибшего из очереди, ограничения контекста, отдача нового модуля и увеличение серверных лимитов. Браузерный прогон с имитацией провайдеров проверяет весь путь от интерфейса до API и обратно. Реальное качество импровизации разных провайдеров требует отдельного запуска.
