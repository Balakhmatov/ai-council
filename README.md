# Кворум — совет нейросетей

Приложение: https://balakhmatov.github.io/ai-council/ . Выбор участников, пять протоколов, обсуждение по раундам и экспорт Markdown. История остаётся в памяти вкладки.

## Пользователь и администратор

Обычный посетитель сразу выбирает доступные модели и запускает обсуждение. Сессия создаётся автоматически, API-ключи и код владельца ему не нужны. Не подключённые модели отмечены «Скоро». Интерфейс использует Quorum API на https://stage.cityai.site/quorum-api; для локального запуска — сервер текущего origin.

Админка: открыть приложение с `?admin=1`, ввести приватный код владельца (серверный PROXY_TOKEN). Сервер проверяет код и возвращает только статусы, названия моделей и счётчики, без API-ключей. После входа кнопка администрирования видна в этой вкладке; выход удаляет код из sessionStorage. Управление ключами выполняется в приватном окружении сервера, а не в публичном браузере. OpenRouter и ручной ввод адресов убраны из пользовательского интерфейса.

Для публичных сессий модель закреплена сервером: KEY + PROVIDER_MODEL необходимы для доступности провайдера. Лимиты по умолчанию: 300 запросов провайдерам в сутки на весь сервис и 60 на IP. Повторный вход не сбрасывает квоту; файл QUOTA_FILE сохраняет её при перезапуске. TRUST_PROXY=true допускается только за доверенным локальным nginx, который перезаписывает X-Real-IP. Хранятся HMAC IP, а не исходные IP; историю обсуждений сервер не сохраняет. Публичные запросы оплачивает владелец API, лимиты не являются точным денежным бюджетом.


## Пять протоколов

1. Консенсус: независимые ответы → взаимная критика → общий проект модератора → отдельное одобрение каждым. При возражении, ошибке или невалидном голосе консенсус не объявляется.
2. Голосование: ответы → доработка → JSON-голоса за финальные варианты → программный подсчёт → сборка победившего ответа. Ничья обозначается явно, компромисс формирует модератор.
3. Судья: независимые ответы → критика → вердикт выбранного участника.
4. Спор ролей: выбранным участникам по порядку назначаются оптимист, скептик, практик, идеалист, аналитик, редактор, пользователь. Затем модератор собирает итог.
5. Мозговой штурм: независимые идеи → развитие чужих идей → синтез.

Модератор выбирается среди участников. Раунды ограничены; автоматического бесконечного спора нет. В каждом раунде все видят одинаковый завершённый предыдущий контекст. Ошибка одного API не стирает ответы других. Общая стоимость зависит от моделей, длины контекста и количества раундов; интерфейс показывает число запросов, а не обещанную цену. Согласие моделей не гарантирует правильность. Нет веб-поиска и независимого фактчекинга.


## Разработка и публикация

Node.js 22+, зависимостей нет. `npm test` — проверки протоколов, прав доступа и квот. `npm start` — локальный сервер на http://localhost:8787. Демо работает без API и явно обозначает заглушки. Для реальных запросов серверу нужны приватные переменные окружения.

GitHub Pages публикует public/ после push в main через .github/workflows/pages.yml. Корневой index.html обеспечивает вход через public/ для публикации из ветки. На GitHub загружаются только исходники; .env.private, runtime/ и резервные копии не публикуются.

В установленном экземпляре API работает отдельным systemd-сервисом quorum-api, за HTTPS nginx /quorum-api/ на stage.cityai.site. Ключи Mistral, OpenAI, Grok заданы в приватном окружении. Grok поддерживает фиксированные endpoint api.x.ai и ddtnew.com; переадресации запрещены. Другие провайдеры становятся доступными после серверной настройки их ключей и PROVIDER_MODEL.
