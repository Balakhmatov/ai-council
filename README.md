# Кворум — совет нейросетей

Приложение: https://balakhmatov.github.io/ai-council/ . Выбор участников, пять протоколов, обсуждение по раундам и экспорт Markdown. История остаётся в памяти вкладки.

## Пользователь и администратор

Обычный посетитель сразу выбирает доступные модели и запускает обсуждение. Сессия создаётся автоматически, API-ключи и код владельца ему не нужны. Не подключённые модели отмечены «Скоро». Интерфейс использует Quorum API на https://stage.cityai.site/quorum-api; для локального запуска — сервер текущего origin.

Админка: открыть приложение с `?admin=1`, ввести приватный код владельца (серверный PROXY_TOKEN). Сервер проверяет код и возвращает только статусы, названия моделей и счётчики, без API-ключей. После входа кнопка администрирования видна в этой вкладке; выход удаляет код из sessionStorage. Управление ключами выполняется в приватном окружении сервера, а не в публичном браузере. OpenRouter и ручной ввод адресов убраны из пользовательского интерфейса.

Для публичных сессий модель закреплена сервером: KEY + PROVIDER_MODEL необходимы для доступности провайдера. Лимиты по умолчанию: 300 запросов провайдерам в сутки на весь сервис и 60 на IP. Повторный вход не сбрасывает квоту; файл QUOTA_FILE сохраняет её при перезапуске. TRUST_PROXY=true допускается только за доверенным локальным nginx, который перезаписывает X-Real-IP. Хранятся HMAC IP, а не исходные IP; историю обсуждений сервер не сохраняет. Публичные запросы оплачивает владелец API, лимиты не являются точным денежным бюджетом.


## Пять протоколов

1. Консенсус: независимые ответы → взаимная критика → общий проект модератора → отдельное одобрение каждым. При возражении, ошибке или невалидном голосе консенсус не объявляется.
2. Голосование: ответы → доработка → JSON-голоса за финальные варианты → программный подсчёт → сборка победившего ответа. Ничья обозначается явно, компромисс формирует модератор.
3. Судья: независимые ответы → критика → вердикт выбранного участника.
4. Спор ролей: выбранным участникам по порядку назначаются оптимист, скептик, практик, идеалист, аналитик, редактор, пользователь. Затем модератор собирает итог.
5. Мозговой штурм: независимые идеи → развитие чужих идей → синтез.

Модератор выбирается среди участников. Раунды ограничены; автоматического бесконечного спора нет. В каждом раунде все видят одинаковый завершённый предыдущий контекст. Ошибка одного API не стирает ответы других. Общая стоимость зависит от моделей, длины контекста и количества раундов; интерфейс показывает число запросов, а не обещанную цену. Согласие моделей не гарантирует правильность. Нет веб-поиска и независимого фактчекинга.


## Разработка и публикация

Node.js 22+, зависимостей нет. `npm test` — проверки протоколов, прав доступа и квот. `npm start` — локальный сервер на http://localhost:8787. Демо работает без API и явно обозначает заглушки. Для реальных запросов серверу нужны приватные переменные окружения.

GitHub Pages публикует public/ после push в main через .github/workflows/pages.yml. Корневой index.html обеспечивает вход через public/ для публикации из ветки. На GitHub загружаются только исходники; .env.private, runtime/ и резервные копии не публикуются.

В установленном экземпляре API работает отдельным systemd-сервисом quorum-api, за HTTPS nginx /quorum-api/ на stage.cityai.site. Ключи Mistral, OpenAI, Grok заданы в приватном окружении. Grok поддерживает фиксированные endpoint api.x.ai и ddtnew.com; переадресации запрещены. Другие провайдеры становятся доступными после серверной настройки их ключей и PROVIDER_MODEL.

## VPS и Telegram

Основной адрес: https://cityai.site/quorum/ . Код установлен в /opt/quorum, закрытое окружение — /etc/quorum/quorum.env, квоты и идентификаторы обработанных Telegram updates — /var/lib/quorum. Отдельный пользователь quorum; systemd quorum-api.service; nginx направляет только /quorum/ в локальный порт 8787. Старый stage-адрес пока совместим. Внешних изменений DNS не требуется.

Установка/обновление проверенной версии на этом VPS: `python3 deploy/install-vps.py` от root из /root/ai-council. Скрипт добавляет изолированный маршрут в активную nginx-конфигурацию, проверяет nginx перед reload, копирует только исполняемые исходники и сохраняет существующие ключи и квоты. Другие приложения не перезапускаются.

Для Telegram нужен отдельный бот, созданный владельцем в @BotFather через /newbot. Токен сохранить в /root/ai-council/.telegram-token с правами 600; этот файл игнорируется Git. Повторить VPS-установку, затем выполнить от root:

```
node --env-file=/etc/quorum/quorum.env /opt/quorum/scripts/configure-bot.mjs
```

Скрипт проверяет бота через getMe, не заменяет чужой webhook, устанавливает /start, /app, /help, кнопку меню Mini App и защищённый webhook. Не нужно вручную добавлять URL через BotFather для открытия кнопкой меню или кнопкой в /start. Главный профильный Launch App и короткое имя Mini App при желании отдельно настраиваются в BotFather. /admin обрабатывается только для TELEGRAM_ADMIN_IDS.

При запуске Mini App клиент передаёт исходный Telegram initData серверу; сервер проверяет HMAC-SHA256, дату (не старше часа), уникальность полей и Telegram user ID. Только ID из серверного списка получает административную сессию. Подмена initDataUnsafe, URL ?admin=1 или client-side user ID не даёт административных прав. Пользовательская квота в Telegram привязана к проверенному ID; в браузере — к IP. Webhook требует X-Telegram-Bot-Api-Secret-Token и игнорирует повторные update_id. Бот отвечает на входящие сообщения в личном чате; его основная функция — запуск Mini App.

Без TELEGRAM_BOT_TOKEN веб-приложение и браузерный вход владельца продолжают работать, Telegram-вход возвращает 503. Подключение реального бота и вход на устройстве в Telegram проверяются после получения нового токена; криптографические проверки и клиентская интеграция покрыты тестами и имитацией Telegram.

Официальная документация: https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app ; https://core.telegram.org/bots/api .

## OpenAI Luna и актуальная дата

OpenAI для новых и обновлённых инсталляций Quorum использует `gpt-6-luna` (Chat Completions, `reasoning_effort: medium`, `max_completion_tokens: 4096`). При установке существующие конфигурации с OpenAI GPT-4/5 автоматически переключаются на Luna; ключи и явно выбранные модели GPT-6 не меняются. Mistral, Grok и прочие модели не переключаются.

Сервер добавляет к системному сообщению **каждого** запроса текущие дату и время UTC непосредственно перед обращением к провайдеру. Модель не должна принимать дату окончания обучения за текущий день. Это не веб-поиск и не гарантия свежести фактов.

Чтобы обновить именно работающий VPS после push в GitHub, от root:

```bash
cd /root/ai-council && git pull --ff-only && python3 deploy/install-vps.py
```

Публичный клиент GitHub Pages обновляется автоматически, но изменение серверной модели и системного контекста вступает в силу лишь после обновления сервиса `quorum-api` на VPS.

## Рабочие направления, результаты и монеты (2026-10-31)

Quorum теперь предлагает пять профессиональных направлений: SMM, маркетинг, реклама, копирайтинг и блогинг. В каждом доступно шесть необязательных подзадач, которые добавляют критерии качества в системные инструкции моделей. Доступны все пять прежних протоколов; названия переписаны человеческим языком. По умолчанию — три раунда, а Grok выбирается для подготовки общего итога, если подключён.

На экране по умолчанию виден только итоговый материал и короткий прогресс этапов. Включите «Показывать обсуждение моделей», чтобы раскрыть ответы и критику всех участников. Кнопка «Скачать .md» экспортирует итог, а при включённом обсуждении также промежуточные раунды. У промежуточных ответов отдельный ориентир на длину; финальный материал не должен искусственно ужиматься до 300 слов.

Mistral закреплён на `mistral-large-2512` (Large 3), не на плавающем `latest`. При установке VPS миграция заменяет прежний `mistral-large-4` и старые алиасы, сохраняя ключи и настройки остальных провайдеров. Используемые официальные цены для предварительного расчёта стоимости: OpenAI `gpt-6-luna` — $0.10/$0.01/$0.50 за миллион входных/кешированных/выходных токенов; Mistral Large 3 — $0.50/$0.05/$1.50. Остальные прокси-тарифы намеренно **не выдумываются**. Это расчёт по стандартным тарифам, а не подтверждённая сумма списания из кабинета провайдера.

Внутренняя тестовая система монет:
- `FREE_START_COINS` (по умолчанию 3) — пробный баланс; `TASK_COIN_COST` (по умолчанию 1) — тестовая стоимость одного задания в монетах. Эти значения пока **не являются коммерческой ценой**.
- Списание выполняется **сервером при запуске задания**, а не браузером по числу обращений. В одном задании разрешён ограниченный набор моделей и ограниченное число API-вызовов; финальная длинная генерация ограничена одним вызовом. Если не удалось получить ни одного успешного ответа, монета возвращается при завершении задания.
- `ACCOUNTING_FILE` хранит балансы и расходы в `/var/lib/quorum/accounting.json`. В админке отображаются токены и расчётная себестоимость по отдельным обращениям, моделям и в сумме. Содержимое промптов не сохраняется в журнале себестоимости.
- В браузере бесплатный баланс пока привязан к HMAC IP; в Telegram — к проверенному Telegram user ID. Для настоящей оплаты потребуется постоянный аккаунт пользователя и полноценный журнал транзакций. Платёжных реквизитов, покупки монет, автоматического списания рублей и активных подписок **пока нет**.
- Тарифы на неделю, месяц и разовые пакеты появятся после замеров себестоимости и определения курса монет; незавершённую платную корзину не показываем пользователям.

Обновление рабочего VPS из `main` после проверки тестов:

```bash
cd /root/ai-council && git pull --ff-only && npm test && python3 deploy/install-vps.py
```

Установка сохраняет приватные ключи и квоты, копирует `economy.mjs` и перезапускает только сервис Quorum.
